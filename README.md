# Caffen_pt

Proposta de site para a **Caffen_pt**, café de especialidade no Porto.

- Página inicial e cardápio (`#cardapio`) num único `index.html`, sem build.
- Aviso de aberto/fechado calculado na hora de Lisboa (quarta fechado, restantes dias 8h–17h).
- Fotos em `img/` (WebP), logótipo vetorizado e embutido como SVG.

## Ver localmente

Abre `index.html` no browser, ou serve a pasta:

```sh
python3 -m http.server
```

## Publicar

Em **Settings → Pages**, escolhe a branch `main` e a pasta `/ (root)`.
